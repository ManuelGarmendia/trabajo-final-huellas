# Trabajo Final - Huellas

## Organización

Huellas es una organización de bien común que promueve el voluntariado y la participación social. Su objetivo es conectar personas, instituciones y comunidades mediante proyectos educativos, comunitarios y de acompañamiento.

## Descripción del proyecto

Este sitio web fue desarrollado como trabajo final de la materia Desarrollo Web.

El objetivo del sitio es presentar la organización, sus programas, su impacto y brindar un espacio para que nuevas personas puedan sumarse como voluntarias.

### Tecnologías utilizadas

- HTML5
- CSS3
- CSS Grid
- Container Queries
- Responsive Design
